프로젝트

    시작하기

    1. 오른쪽 위 ⚙ 모델 설정에서 쓸 모델을 고릅니다 (Codex CLI · Claude Code CLI · OpenAI API 키 · Anthropic API 키).
    2. 왼쪽에서 프로젝트를 만들고 자료 탭에 회의록·아이디어·수정사항·참고문서를 넣습니다.
    3. 실행 탭에서 시작을 누르면 분석 → 설계 → 구현 → 시험 순으로 산출물을 씁니다.
    4. 결과 탭에서 Word 파일과 검토 리포트를 내려받습니다. 근거가 부족한 산출물은 만들지 않고 이유를 남깁니다.

    파일 넣기

    여기로 파일을 끌어다 놓아도 됩니다 (txt, md, docx, hwp, hwpx, pdf)

    텍스트 붙여넣기

    넣은 자료

    ※ 입력 자료는 선택한 AI 서비스로 전송됩니다. 반출이 제한된 자료는 넣지 마세요. 주민번호·전화·이메일·카드번호는 자동으로 가려지지만 이름·주소는 직접 지워야 합니다.

    실행

    수정사항 반영

    자료 탭에 '수정사항' 종류로 넣은 요청을 기존 산출물에 반영합니다. 영향 범위와 회의 결정과의 충돌을 먼저 보여 드리고, 체크한 변경만 반영합니다.
