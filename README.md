# SW 표준 산출물 자동 작성 킷

「CBD(Component Based Development) SW개발 표준 산출물 관리 가이드」(2011.12)의 필수 산출물 25종과 선택 산출물 2종을
회의록·아이디어·수정사항으로부터 **가이드 양식 그대로(Word)** 작성하는 Claude Code 스킬입니다.

- 입력 자료에 **근거가 있는 내용**은 그대로 채웁니다.
- 가이드 작성 방법상 **도출되는 설계**(클래스, 테이블, 시험케이스 등)는 AI가 작성하되 **노란 음영(검토 전)** 으로 표시합니다.
- 근거가 없는 칸은 `(정보 부족)`, 논의됐지만 결정되지 않은 칸은 `(미정)`으로 남기고, 채우는 데 필요한 **질문지**를 만듭니다.
- 요구사항 추적표, DB 생성 스크립트(DDL), 결과서 뼈대, 모든 다이어그램은 프로그램이 자동으로 만듭니다.

## 설치

필요: Windows/macOS/Linux, Node.js 18+, Chrome 또는 Edge(다이어그램 렌더링), Claude Code.

```powershell
# 프로젝트 폴더에 설치
powershell -ExecutionPolicy Bypass -File install.ps1 -Target "D:\my-project"
# 또는 모든 프로젝트에서 쓰도록 사용자 전체 설치
powershell -ExecutionPolicy Bypass -File install.ps1 -Scope User
```

설치 시 런타임(약 460MB, 주로 Mermaid 다이어그램 엔진)을 `%LOCALAPPDATA%\sw-deliverables\runtime`에 한 번만 설치하고
모든 프로젝트가 공유합니다.

## 사용법

1. 프로젝트 폴더를 Claude Code로 열고 **"이 프로그램 기반으로 산출물 작성해줘"** 라고 요청합니다.
2. 처음이면 `deliverables/` 폴더가 만들어집니다. `deliverables/input/` 아래에 자료를 넣습니다.
   - `회의록/` `아이디어/` `수정사항/` `참고문서/` (txt, md, docx, hwp, hwpx, pdf)
3. AI가 자료를 읽고 시스템명·서브시스템 구분을 제안합니다 → 확인해 주세요(설정은 `sw-config.yaml`에 고정됩니다).
4. 단계마다(분석 → 설계 → 구현 → 시험) 서브시스템별로 **병렬 작성** → 검증 → 문서 생성 → **확인 요청**을 반복합니다.
   - 확인 화면에서 AI 제안 목록, 미정 항목, 질문지(`output/_검토/검토리포트_*.md`)를 보고 승인하거나 수정을 요청합니다.
5. 나중에 수정사항이나 새 회의록을 `input/`에 넣고 **"수정사항 반영해줘"** 라고 하면, 영향 범위와 충돌을 보여준 뒤 확인을 받아 반영하고
   제·개정 이력을 남깁니다.

결과물: `deliverables/output/<서브시스템>/<산출물ID>_<산출물명>.docx` (산출물 ID는 가이드 규칙 `프로젝트_서브시스템_코드_010`).

## 구조

```
.claude/
├─ skills/sw-deliverables/
│   ├─ SKILL.md            마스터 에이전트 절차서(단계·게이트·병렬 작성·수정사항 반영)
│   ├─ schema/             가이드를 기계가 읽는 형태로 옮긴 산출물 27종 정의(필드·작성 방법·양식 레이아웃)
│   ├─ reference/          작성 원칙, 회의록 추출법, ID 규칙, 다이어그램 스타일, 보안 주의사항, 명령 참고서
│   ├─ templates/          sw-config 템플릿
│   └─ scripts/swd.mjs     검증기·렌더러(DOCX)·다이어그램·추적표·DDL·검토 리포트·지시서 생성기
└─ agents/sw-deliverable-writer.md   서브시스템별 작성 서브에이전트
```

동작 원리: **AI는 문서를 직접 쓰지 않고 `model/*.yaml` 데이터만 채웁니다. 문서는 프로그램이 가이드 양식대로 찍어냅니다.**
그래서 양식은 항상 같고, 모든 값은 출처(입력 파일의 줄 번호)나 AI 제안 표시를 가집니다.

## 보안 주의사항

- 입력 자료는 AI 서비스로 전송되어 처리됩니다. 발주처 보안 규정상 반출이 제한된 자료는 넣지 마세요.
- 주민등록번호·전화번호·이메일·카드번호는 정규화 단계에서 자동으로 가려지지만, 이름·주소 등은 직접 지워야 합니다.
- 계정·비밀번호·IP 등 비밀 정보는 입력과 산출물에 쓰지 않습니다. `input/`과 `.work/`는 형상관리에서 제외됩니다.
- 노란 음영이 남은 문서는 검토 전 문서입니다. 확인 후 제출하세요.

## 한계

- 실제 코드·환경·시험이 필요한 칸(프로그램 목록, 시험결과, 설치 결과, 화면 캡처)은 자료를 줄 때만 채워집니다.
- 화면 레이아웃은 입출력 항목으로 그린 참고용 와이어프레임입니다.
- HWP(한글) 출력은 지원하지 않습니다(DOCX를 한글에서 열어 저장하면 됩니다).
