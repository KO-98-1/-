# 보안 주의사항

최초 실행 시 사용자에게 한 번 안내하고, `sw-config.yaml`의 `security.notice_shown`을 `true`로 바꾼다.

1. **입력 자료는 AI 서비스(클라우드)로 전송되어 처리된다.** 발주처 보안 규정(정보시스템 구축·운영 지침, 계약상 비밀유지 조항)상
   반출이 제한된 자료는 입력하지 않는다. 공공·금융 사업은 사전에 발주처 보안 담당자 확인을 권장한다.
2. **개인정보:** `swd ingest`가 정규화 텍스트에서 주민등록번호·전화번호·이메일·카드번호를 자동으로 가린다(`mask_pii`).
   이름·주소 등은 가려지지 않으므로 필요하면 원본에서 먼저 지운다. AI는 원본(`input/`)이 아니라 정규화본(`.work/inputs/`)만 읽는다.
3. **비밀 정보:** 계정·비밀번호·접속 정보·IP·보안 설정값은 입력 자료와 산출물에 쓰지 않는다. 시스템 설치 결과서(T5)의
   계정·비밀번호 칸은 비워 두고 별도 보안 문서로 관리한다.
4. **저장소 관리:** `init`이 만드는 `.gitignore`는 `input/`과 `.work/`를 제외한다. 산출물(`output/`)만 형상관리한다.
5. **외부 공유:** 생성된 산출물에 AI 제안 음영이 남아 있으면 검토가 끝나지 않은 문서다. 확인(`swd confirm`) 후 제출한다.
